# Сергеев: Свет есть

Одиночная HTML-игра для ПК из пяти миссий. Кнопка «Начать играть» всегда открывает пролог и запускает новую кампанию. Контрольные точки работают до выхода в меню или закрытия страницы.

## Запуск

Открой терминал в папке с файлом `index.html` и запусти статический сервер.

```sh
python3 -m http.server 8080 --bind 127.0.0.1
```

Открой [игру](http://127.0.0.1:8080/) в браузере. Игра заполняет окно браузера, использует нативные ES-модули и запускается через HTTP без сборщика. Чтобы остановить сервер, вернись в Терминал и нажми **Control + C**.

Для GitHub Pages распакуй содержимое архива в корень выбранной ветки, включая файл `.nojekyll`. Все ресурсы подключаются по относительным путям.

Ресурсы каждой миссии загружаются на её сюжетной заставке. Индикатор показывает ход загрузки, а общие ресурсы повторно используются в следующих миссиях.

## Управление

Перед первой миссией появится окно с основными клавишами. Нажми **Пробел**, чтобы закрыть его и начать миссию.

| Клавиши | Действие |
| --- | --- |
| ← → или A D | Движение |
| Мышь | Прицеливание в пеших миссиях |
| ↑ ↓ или W S | Смена полосы на велосипеде. Резервное прицеливание клавишами, когда курсор вне поля |
| ↓ или S на платформе | Спрыгнуть с платформы |
| Пробел | Прыжок. На земле высота зависит от длительности нажатия |
| J или Z, нажатие мыши на игровом поле | Огонь |
| K или X | Таунт. Ближайший демон сближается и становится уязвимее |
| L или C | Суперзалп при полном заряде. Заряд дают убитые демоны |
| E | Терминал, рубильник или фиксация подвеса |
| Esc или P | Пауза |

После поражения выбери «Повторить», чтобы вернуться к контрольной точке. Бой с демоном-крановщиком при повторе начинается заново.

На велоуровне дорога разделена на четыре пронумерованные полосы. Бирюзовая подсветка показывает выбранную полосу героя, оранжевые метки под противниками показывают их полосы.

В пеших миссиях курсор задаёт направление обычного выстрела. В стойке герой поворачивается к курсору. При движении курсор за спиной даёт горизонтальный выстрел по ходу бега. Предел подъёма оружия около 73° в стойке и 45° на бегу.

Музыка звучит уже в главном меню. Если браузер блокирует автовоспроизведение, нажми на фон меню или клавишу. Пауза и переключение вкладки приостанавливают звук. Выстрелу крановщика предшествует звуковой сигнал заряда.

## Структура проекта

| Папка | Ответственность |
| --- | --- |
| `src/mechanics/player/` | Движение, прицел, здоровье и выбор кадров |
| `src/mechanics/combat/` | Демоны, навигация по платформам, снаряды, попадания и эффекты |
| `src/mechanics/bike/` | Четыре полосы, прыжок, препятствия и погоня |
| `src/mechanics/world/` | Платформы, камера, контрольные точки, рубильники и волны |
| `src/mechanics/boss/` | Фазы, атаки и аптечки в бою на видеокарте |
| `src/levels/` | Разметка миссий, сюжетные сцены и реплики |
| `src/render/` | Canvas, наборы ассетов и параллакс |
| `src/engine/`, `src/ui/` | Игровая сессия, ввод, меню и переходы |
| `src/audio/`, `assets/audio/` | Микшер Web Audio, звук сцен и ресурсы MP3 |

## Графика и анимации

Меню и сюжетные иллюстрации используют утверждённый вариант 3 Сергея Михайловича. В меню логотип, герой и улица находятся на отдельных слоях. Перемещение курсора сдвигает улицу, героя и атмосферные эффекты с разной скоростью. В игровых уровнях небо, горизонты, фасады и игровые поверхности двигаются относительно камеры. Вертикальный параллакс задан в `src/render/backdrops.js`. Игровое поле масштабируется с фильтрацией nearest neighbor.

Игровые атласы героя — `marine-right-core-matched.webp`, `marine-right-extra-matched.webp` и `marine-run-up.webp`. Бег и бег с прицелом вверх используют цельные кадры. При наведении мышью верх кадра наклоняется вокруг оружия, переход в области пояса сохраняет опору ног и фазу шага. Вспышка и снаряд берут координаты из положения дула. На велосипеде меняется поза верхней части тела, колёса вращаются от пройденного пути, а снаряды летят горизонтально. Для портала используется четыре сменяющих друг друга кадра.

Атласы босса `crane-walk.webp` и `crane-actions.webp` добавляют кадры ходьбы, выстрела, взмаха клешнёй, реакции на попадание и падения. Шаги синхронизированы с перемещением босса по видеокарте.

Для вида улиц и подстанции использовались фотографии Бузулука и Оренбургской области. Погоня ориентируется на смену ритма в Turbo Tunnel.
